# ModBus参数

设备连接采用ModBus-TCP通信的第三方EMS时，需设置。

<table><thead><tr><th width="79">序号</th><th width="148">参数名称</th><th>说明</th></tr></thead><tbody><tr><td><strong>1</strong></td><td>ModBus Server Address</td><td>设置设备作为Modbus TCP客户端时，第三方EMS服务器地址。</td></tr><tr><td><strong>2</strong></td><td>ModBus Server Port</td><td>设置设备作为Modbus TCP客户端时，和第三方EMS通信的端口。</td></tr><tr><td><strong>3</strong></td><td>ModBus Local (Slave) Address</td><td>设置使用Modbus协议时，设备的Modbus地址。 并机场景时，设备的Modbus地址需配置不同。</td></tr><tr><td><strong>4</strong></td><td>ModBus TCP Server Enable</td><td>设置为<img src="../../../.gitbook/assets/0 (15).png" alt="" data-size="line">时，设备作为Modbus Tcp服务器，允许第三方EMS连接。</td></tr></tbody></table>
