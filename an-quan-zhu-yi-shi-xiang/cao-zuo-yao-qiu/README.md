# 操作要求

{% include "../../.gitbook/includes/danger.md" %}

<mark style="color:red;">高电压、危险：</mark>

* <mark style="color:red;">禁止带电操作（包含但不限于安装、接线、更换等）。在操作前，请确保设备所有供电电源已断开，包含但不限于电网侧、逆变器和柴油发电机电源开关。带电操作可能造成火灾、电击、电弧或爆炸，导致人员伤亡或财产损失。</mark>
* <mark style="color:red;">禁止在未完成安装或未经专业人员评估的情况下给设备上电。</mark>
* <mark style="color:red;">禁止在恶劣天气时（包含但不限于雷电、雨、雪、台风等）操作设备。</mark>
* <mark style="color:red;">禁止将设备长时间暴露于高温环境或发热源长时间在设备周围（如日照、火源、取暖器等）。</mark>
* <mark style="color:red;">禁止用水、酒精、油等清洗或浸泡设备，以免造成设备漏电等。</mark>
* <mark style="color:red;">禁止撞击、拖动或踩踏设备。若意外发生撞击，请立即停止使用设备并及时您的销售代理商，设备经专业人员检查评估后方可继续使用。</mark>
* <mark style="color:red;">操作设备前，请检查设备无损坏。若有异常（如外观变形、有异味等），请及时联系您的销售代理商处理，禁止自行拆解设备。</mark>
* <mark style="color:red;">操作设备时，发现设备异常或出现可能导致人身伤害的情况时（如外观变形、有异味、电弧等），请立即停止操作，及时向负责人反馈，并采取有效措施。</mark>
* <mark style="color:red;">操作设备时，请穿戴绝缘手套、绝缘鞋、安全帽等防护用具。禁止佩戴金属手镯、戒指、项链等导电饰品。</mark>
* <mark style="color:red;">安装、接线时，请使用绝缘工具。</mark>
* <mark style="color:red;">需要接地的设备永久连接保护地。连接线缆时，必须首先连接保护地线；更换设备时，必须最后拆除保护地线。</mark>
* <mark style="color:red;">禁止徒手或使用导体、潮湿物体接触设备端子。接触设备端子之前，测量接触点电压，确保无电击危险。</mark>
* <mark style="color:red;">操作设备过程中，禁止将异物掉落至设备内部，否则可能导致设备短路故障或损坏、负载供电降额或掉电，甚至人身伤害。</mark>
* <mark style="color:red;">对10kV及以上的中压侧设备下电时，建议先关闭逆变器和断开低压侧设备开关。</mark>
* <mark style="color:red;">设备表面出现油漆划伤，请及时进行补漆。</mark>

{% include "../../.gitbook/includes/warning.md" %}

* <mark style="color:orange;">禁止停用设备中的保护装置，包含但不限于防护盖、防雷器等。</mark>
* <mark style="color:orange;">设备运行时，散热区域处温度较高，请勿触摸。</mark>
* <mark style="color:orange;">设备运行时，禁止盖住散热区域，保持300–600mm的散热通道，以免高温起火。</mark>

{% include "../../.gitbook/includes/caution.md" %}

* <mark style="color:purple;">设备需要获得所在国家、地区电力许可，方可并网运行。</mark>
* <mark style="color:purple;">禁止使用有破损或不合格的线缆、工具，操作设备前，请检查所用线缆、工具应符合要求，并进行登记；完成操作后，进行清点回收，避免遗落在设备内，造成安全隐患。</mark>
* <mark style="color:purple;">操作设备时，请遵守所在国家、地区电站安全规范，包含但不限于执行操作票、工作票等。</mark>
* <mark style="color:purple;">推荐场所中备二氧化碳灭火器或ABC干粉灭火器。</mark>
* <mark style="color:purple;">非工作人员禁止进入操作场所，请在操作场所周围加装临时围栏或警示绳，并悬挂“非工作人员禁止进入”等相关标识牌。</mark>
* <mark style="color:purple;">禁止人为遮挡、破坏设备上的警示标识或铭牌，若发现警示标识或铭牌由于长期使用有破损、不清晰，请及时更换。</mark>
* <mark style="color:purple;">操作、维护设备前，请检查设备顶部是否有积水、积雪或其他杂物，若有，请先清理。</mark>

### 禁止设备用于以下场景：

* 连接公共基础系统设施（如红绿灯、安保系统等）。
* 连接急救医疗设施。
* 连接电梯等控制设备。
* 任何其他类似场景等。
