# ケーブル接続

{% include "../.gitbook/includes/danger.md" %}

* <mark style="color:red;">ケーブルを接続する前に、機器に損傷がないことを確認してください。さもないと、感電や火災の危険があります。</mark>
* <mark style="color:red;">ケーブルを接続したり、取り外したりする前に、機器の上流および下流のスイッチと機器自体のスイッチが切断されていることを確認してください。</mark>
* ケーブルが絡んでいないか、または交差していないか確認してください。カテゴリごとにケーブルを束ねておくようお勧めします。長さが足りない電源コードは交換してください。電源コードを繋いだり、はんだ付けすることは固く禁じられています。
* 横方向の力が加わったときに端子が破損しないよう、機器に対して垂直方向にケーブルを挿入する必要があります。
* 機器の吸気口や排気口にケーブルを通さないでください。
* 絶縁体が破損しているケーブルは使用しないでください。ケーブルの穴の周囲が鋭く尖っていないか、またはバリがないか確認してください。長さが足りないケーブルは交換してください。溶接などの方法でケーブルを延長しないでください。
* 機器の接地インピーダンスは、国や地域の規格に準拠する必要があります。
* 配線方法および温度や湿度などの環境条件が変化した場合、IEC-60364-5-52もしくはお住まいの地域の法律や規制を参照してケーブルを選択してください。
* 高温によるケーブルの経年劣化を避けるため、ケーブルを熱源から100 mm以上離してください。
* 周囲温度が低いほど、プラスチックケーブルの被覆が脆くなります。敷設中に被覆の割れを防止するため、0°C以上の温度でケーブルを敷設し、輸送中に注意して取り扱ってください。ケーブルが長時間0°C以下の環境で保管されている場合、再使用する前に少なくとも24時間、0°C以上の環境に移しておきます。
* ケーブルを敷設する前に、ケーブルに、適切なラベルが貼付され、絶縁されており、識別記号が表示されていることを確認してください。ラベルや敷設手順書に従って、ケーブルを正しく完全に接続してください。
* 地下に配線する場合は、ケーブルトレイとクリップでケーブルを固定してください。埋め戻す前に、埋め戻した場所でケーブルが地面に対して確実に固定されるよう、適度なケーブル長を確保してください。さもないと、ケーブルに応力が加わって、端子が変形・破損したり接続が緩む恐れがあります。
* 機器を設置する際は、適切な範囲のトルクレンチでねじを締め付けます。レンチで締め付ける際は、レンチが傾いていないことを確認し、トルクの誤差が規定値の10%を超えてはなりません。
