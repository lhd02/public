# 作業要件

{% include "../.gitbook/includes/danger.md" %}

<mark style="color:red;">高電圧と危険性：</mark>

* <mark style="color:red;">電源をオンにした状態で機器で作業を実施しないでください（これには設置、配線、交換が含まれますが、それだけに限りません）。作業の前に、機器へのすべての電源が切断されていることを確認してください（これにはグリッド側、インバーターおよびディーゼル発電機電源スイッチが含まれますが、それだけに限りません）。電源を入れたまま操作を実施すると、火災、感電、アーク放電、爆発によって、人身事故や施設の破損が発生する恐れがあります。</mark>
* <mark style="color:red;">インバーターが電力網に接続されている場合、ストリングやストリングのコンポーネントの接続や切断など、DC入力ケーブルの保守作業を実行しないでください。感電やアーク火災の原因となる恐れがあります。</mark>
* <mark style="color:red;">設置評価または専門家による評価が完了するまで、機器の電源を入れないでください。</mark>
* <mark style="color:red;">悪天候下に機器で作業をしないでください（これには雷、雨、雪などが含まれますが、それだけに限りません）。</mark>
* <mark style="color:red;">日光、発火源、ヒーターなどの高温や熱源に、長時間機器をさらさないでください。</mark>
* <mark style="color:red;">漏電や感電を防ぐため、機器を水、アルコール、油などの液体で洗浄したり、その中に浸漬しないでください。</mark>
* <mark style="color:red;">機器を叩いたり、引きずったり、踏みつけたりしないでください。誤って衝撃が加わった場合、直ちに機器の使用を中止し、販売担当者に連絡してください。機器を再稼働する前に、専門家によって検査と評価を受ける必要があります。</mark>
* <mark style="color:red;">機器を操作する前に、破損個所がないか確認してください。外観の変形や異臭などの異常が認められた場合、ご自分で機器を分解してはなりません。必ず販売担当者に連絡してください。</mark>
* <mark style="color:red;">外観の変形、異臭、アーク放電など装置が異常動作したり、人身事故の原因となる事象が認められた場合、直ちに操作を中止し、販売担当者に連絡して、有効な対策を講じてください。</mark>
* <mark style="color:red;">装置を操作する際は、絶縁手袋、絶縁靴、安全帽子など個人用保護機器を着用してください。</mark>金属製のブレスレット、指輪、ネックレスなどの導電性アクセサリーは着用しないでください。
* <mark style="color:red;">設置や配線の際には、絶縁工具を使用してください。</mark>
* <mark style="color:red;">接地が必要な機器は、PGNDに常時接続してください。ケーブルを接続する前に最初の手順としてPGNDを接続し、装置を交換する際には最後の手順としてPGNDを外してください。</mark>
* <mark style="color:red;">素手、導体、湿った物で端子に触れないでください。感電を防止するため、端子に手を触れる前に、接点の電圧を測定してください。</mark>
* <mark style="color:red;">機器の動作中は、機器内に異物が入らないよう注意してください。異物が入ると、機器が短絡または破損したり、負荷への供給電力が低下したり、停電することがあり、最悪の場合には人身事故が発生することもあります。</mark>
* <mark style="color:red;">機器表面の塗装の傷を補修してください。</mark>

### 安全関連の要件

* <mark style="color:red;">機器を長時間高温環境に曝さないでください。また、機器の周囲に熱源（日光、火気、ヒーターなど）を近づけないでください。</mark>
* <mark style="color:red;">漏電などの問題を防止するため、水、アルコール、油などで機器を洗浄したり、その中に浸漬しないでください。</mark>
* <mark style="color:red;">機器に打撃や衝撃を与えないでください。誤って衝撃が加わった場合、直ちに機器の使用を中止し、速やかに設置業者または販売担当者に連絡してください。衝撃が加わった機器は、専門家による検査と評価を受けた場合に限り、再使用できます。</mark>

{% include "../.gitbook/includes/warning.md" %}

* <mark style="color:orange;">保護装置（これには保護カバーやサージアレスターなどが含まれますが、それだけに限りません）を無効にしないでください。</mark>
* <mark style="color:orange;">機器の動作中は、放熱エリアの高温面に手を触れないでください。</mark>
* <mark style="color:orange;">機器の動作中は、高温による火災を防止するため、放熱エリアが覆われないように、300mmないし600mmの放熱経路を確保してください。</mark>

{% include "../.gitbook/includes/caution.md" %}

* <mark style="color:purple;">機器を電力網に接続する前に、機器が設置されている国や地域の電力会社からライセンスを取得する必要があります。</mark>
* <mark style="color:purple;">損傷したケーブルや工具、不適切なケーブルや工具は使用しないでください。機器を操作する前に、ケーブルと工具がすべて必要な条件を満たしていることを確認し、記録を付けておいてください。操作が完了したら、危険な状況を回避するため、在庫状況を確認し、ケーブルや工具が機器内に残っていないように、すべて回収してください。</mark>
* <mark style="color:purple;">機器を操作する際は、機器が設置されている国や地域の発電所の安全規則（操作札や作業札の設置などが含まれますが、それだけに限りません）を遵守してください。</mark>
* <mark style="color:purple;">二酸化炭素消火器やABC粉末消火器が推奨されます。</mark>
* <mark style="color:purple;">関係者以外が操作現場に近づかないようにしてください。作業場所の周囲に柵を仮設するか警告ラインを張り、「関係者以外立入禁止」等の標識を設置してください。</mark>
* <mark style="color:purple;">機器の警告ラベルや銘板が隠れたり、破損させることがないよう注意してください。警告ラベルや銘板が破損している場合、もしくは長期間使用したため明瞭に判読できない場合は、交換してください。</mark>
* <mark style="color:purple;">機器の操作や保守を行う前に、機器の上に水や雪などの異物が付着していないことを確認してください。必要に応じて清掃してください。</mark>

### **以下の場面では機器を使用しないでください。**

* 信号機やセキュリティシステムなどの公共インフラストラクチャシステムに接続されている時。
* 救急医療機器に接続されている時。
* 昇降機やその他の制御装置に接続されている時。
* その他の光学系システムに接続されている時。
