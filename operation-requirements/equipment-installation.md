# 機器の設置

{% include "../.gitbook/includes/warning.md" %}

* <mark style="color:orange;">機器を設置する前に、納品前に取り付けてあるねじが締め付けてあることを確認してください。納品前に締め付けてあるねじには線が引いてあります。線がずれている場合、ねじが緩んでいることを意味します。その場合はねじを締め直してください。</mark>

* <mark style="color:orange;">機器の落下による怪我を防止するため、機器を取り扱う際は、耐荷重に十分注意してください。</mark>

### **梯子の安全性**

* 十分な訓練や指導を受けていない者ははしごを使用しないでください。
* 不適格な梯子を使用しないでください（これには損傷した梯子、壊れた梯子、変形した梯子、仮の梯子が含まれますが、それだけに限りません）。
* 耐荷重要件を満たさない梯子を使用しないでください。
* 電気作業を行うためにはしごに登る場合、木製またはグラスファイバー製のはしごを使用してください。
* まっすぐなはしごを、60°～70°の傾斜に立てかけます。
* はしごの上で作業している場合、高所から物を投げないでください。
* はしごの上で作業する場合は、監視者を指名するようお勧めします。
* 通路の入り口で梯子を使用する場合には、ドアをロックしておくようにしてください。

### **持ち上げ作業時の安全確保**

* 持ち上げを行う作業員は、作業場所に配置される前に適切な訓練を受け、資格を取得しておく必要があります。
* 持ち上げエリアを隔離するため、警告標識かフェンスを仮設してください。
* 持ち上げ作業を行う場所の基礎は、クレーンの耐荷重要件を満たす必要があります。
* 持ち上げ作業を行う前に、揚重機が、耐荷重基準を満たす固定物か壁面に確実に固定されていることを確認してください。
* 持ち上げ作業中は、絶対に、ブームや持ち上げた物体の下を歩いてはなりません。
* 持ち上げ作業中は、ワイヤーロープや揚重機を引きずったり、硬い物で叩いてはなりません。
* 持ち上げ作業中は、下図に示すように、2本のスリング間の角度が90°を超えないように注意してください。

### **ドリル作業の安全性**

* 機器にドリルで穴をあけないでください。
* ドリルで穴をあける際には、安全ゴーグルと保護手袋を装着してください。
* 機器に破片が落ちないようにするために、ドリルで穴をあける箇所の近くに機器を置かないでください。
* 穴を開けた後は、直ちに削り屑を除去してください。
