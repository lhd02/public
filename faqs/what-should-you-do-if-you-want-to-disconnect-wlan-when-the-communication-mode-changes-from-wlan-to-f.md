# What should you do if you want to disconnect WLAN when the communication mode changes from WLAN to F

1. Insert the network cable into the device.
2. On the "Home" screen, click the station name you want to set.
3. Click <img src="../.gitbook/assets/0 (29).png" alt="" data-size="line"> next to the station name and click "System Settings" → "Connectivity.”
4. Wait until "Ethernet" is connected, click "WLAN,” and then select any WLAN and enter an invalid password.
