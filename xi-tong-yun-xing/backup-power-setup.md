# Opsætning af backupstrøm

{% include "../.gitbook/includes/tips.md" %}

* <mark style="color:blue;">Spring dette afsnit over, hvis der ikke er konfigureret nogen gateway.</mark>
* <mark style="color:blue;">Brugere kan manuelt indstille denne parameter i henhold til strømafbrydelsesfrekvensen i deres regioner og afgangstid.</mark>

Hvis der er en gateway i dit netværk, kan du manuelt indstille værdien for »Backup Reserve« i mySigen-appen. I netforbindelsestilstand stopper batteriet med at aflade, når SOC-indstillingen for backupstrøm er nået. I tilfælde af strømafbrydelse bliver backupstrømmen tilgængelig.

For eksempel er backup-strømforsyningens SOC indstillet til selvforbrugstilstand.
