# ModBus Settings

You need to set these parameters when the device is communicated with a third-party EMS over the ModBus-TCP protocol.

<table><thead><tr><th width="60" align="center">No.</th><th width="195.7777099609375">Parameter name</th><th>Description</th></tr></thead><tbody><tr><td align="center">1</td><td>Modbus Native (Slave) Address</td><td>Specifies the Modbus address of the device when the Modbus protocol is used.You must set different Modbus addresses for devices in parallel mode.</td></tr><tr><td align="center">2</td><td>ModBus TCP Server Enable</td><td>When this parameter is set to <img src="../../.gitbook/assets/2 (5) (1).png" alt="" data-size="line">, the device functions as the Modbus TCP server and enables connection with a third-party EMS.</td></tr><tr><td align="center">3</td><td>Rs485-1 Port Mode</td><td>Specifies the port for the device to communicate with a third-party EMS when the device functions as the Modbus TCP client.</td></tr></tbody></table>
