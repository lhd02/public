# （可选）V2X功能开通与开启

{% include "../../.gitbook/includes/tips.md" %}

* <mark style="color:blue;">若要开通V2X功能，需将SigenStor软件版本升级到SPC110。</mark>
* <mark style="color:blue;">开启V2X功能后，将直流充电桩作为额外的“储能”，参与整个电站的调度，为家用设备或电网放电。</mark>
