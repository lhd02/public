# （可选）V2X功能设置

{% include "../../.gitbook/includes/tips.md" %}

* <mark style="color:blue;">开通V2X功能后，可将直流充电桩作为额外“储能”参与电站调度，为家用设备供电。</mark>
* <mark style="color:blue;">当SigenStor软件版本为SPC110及以上时，可支持V2X功能。</mark>

<figure><img src="../../.gitbook/assets/MSA1CM00101-开通V2X.png" alt="" width="563"><figcaption></figcaption></figure>

* 首次开通V2X功能时，点击“双向V2X操作”，需签署风险告知协议、填写车型等基础信息后方可将“双向V2X操作”设置为![](../../.gitbook/assets/image.png)。
* 当“授权”设置为![](../../.gitbook/assets/image.png)，且充电枪已经安装到位时，您可通过“添加手动控制”设置直流充电桩放电时间段与功率。若直流充电桩在设置的时间段内放电时，您想强制停止，可点击“停止放电”。
