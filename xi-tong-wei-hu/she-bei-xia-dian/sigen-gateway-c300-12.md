# Sigen Gateway (C600, C1200, C600-B, C1200-B)

<figure><img src="../../.gitbook/assets/SGA1IN00169-下.png" alt="" width="375"><figcaption></figcaption></figure>

{% include "../../.gitbook/includes/warning.md" %}

<mark style="color:orange;">Das Gateway sollte in der folgenden Reihenfolge getrennt werden:</mark>

1. <mark style="color:orange;">Schalten Sie den Leistungsschalter des Rahmens QA3 aus (anschlossen an eine Notstromlast).</mark>
2. <mark style="color:orange;">Schalten Sie den Rahmen-Leistungsschalter QA2 (angeschlossen an einen Dieselgenerator/intelligenten Last) aus.</mark>
3. <mark style="color:orange;">Nachdem Sie die Wechselrichter über das Telefon ausgeschaltet haben, schalten Sie die an die Wechselrichter angeschlossenen Leistungsschalter aus.</mark>
* <mark style="color:orange;">C600: Schalten Sie 2QF1~2QF30 (Leistungsschutzschalter) aus</mark>
* <mark style="color:orange;">C1200: Schalten Sie 2QF1 bis 2QF50 (Miniatur-Leistungsschalter) aus</mark>
* <mark style="color:orange;">C600-B: Schalten Sie 2QF1~2QF10 (Leistungsschalter) aus</mark>
* <mark style="color:orange;">C1200-B: Schalten Sie 2QF1~2QF20 (Leistungsschalter) aus</mark>
4. <mark style="color:orange;">Schalten Sie den an das Stromnetz angeschlossenen Leistungsschalter (Rahmen) QA1 aus.</mark>
5. <mark style="color:orange;">Schalten Sie die Schalter der Überspannungsableiter 1QF2, 1QF4 und 1QF6 aus.</mark>
6. <mark style="color:orange;">Schalten Sie den Sekundärsteuerschalter der Leiterplatte 1QF1, 1QF3, 1QF5 aus, schalten Sie den Sekundärsteuerschalter des Rahmen-Leistungsschalters 1QF7, 1QF8, 1QF9, 1QF10 aus.</mark>
