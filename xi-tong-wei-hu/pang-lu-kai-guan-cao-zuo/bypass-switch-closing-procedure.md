# Postup zavření přemosťovacího spínače

{% include "../../.gitbook/includes/tips.md" %}

<mark style="color:blue;">**Když abnormální provoz síťového stykače zařízení Gateway zabrání dodávce napájení do spotřebiče, uzavřete přemosťovací spínač, aby byl spotřebič napájen přímo ze sítě.**</mark>

### **Kroky**

1. Zkontrolujte, zda síť dodává normálně napájení.
2. Vypněte napájení podle pokynů v&nbsp;části [Vypnutí napájení](../she-bei-xia-dian/).
3. Řiďte se dobou prodlevy uvedenou na štítku zařízení a&nbsp;vyčkejte stanovenou dobu. Po uplynutí doby sundejte pojistný kroužek z&nbsp;přemosťovacího spínače a&nbsp;zapněte přemosťovací spínač.

<figure><img src="../../.gitbook/assets/SGA1IN00153-en-01.jpg" alt="" width="326"><figcaption></figcaption></figure>

{% include "../../.gitbook/includes/warning.md" %}

* <mark style="color:orange;">Okamžitě po vypnutí zůstává v&nbsp;zařízení zbytkový proud a&nbsp;zařízení je horké. Provoz zařízení ihned po vypnutí napájení může vést k&nbsp;úrazu elektrickým proudem nebo popáleninám.</mark>
* <mark style="color:orange;">V&nbsp;zařízení je přítomno vysoké napětí. Při zapínání spínače noste izolační rukavice.</mark>

{% include "../../.gitbook/includes/caution.md" %}

<mark style="color:purple;">Po zapnutí přemosťovacího spínače nezapínejte miniaturní jistič připojený k&nbsp;měniči a&nbsp;generátoru na zařízení Gateway. Jinak bude port energetické sítě nabíjen, což bude mít za následek riziko úrazu elektrickým proudem.</mark>

4. Zapněte miniaturní jistič připojený k&nbsp;SPD.
5. Zapněte miniaturní jistič připojený k&nbsp;energetické síti.
6. Zapněte miniaturní jistič připojený k&nbsp;zálohovaným domácím spotřebičům.
7. Zavřete dveře zařízení.
