# Encendido/apagado del equipo

### **Sistema 1: Funcionamiento de la aplicación**

En la aplicación mySigen, toque «Ajustes» para encender o apagar el dispositivo.

<figure><img src="../.gitbook/assets/SSA1CM00001-es (2).png" alt="" width="563"><figcaption></figcaption></figure>

### Sistema 2: Operación manual

Siga los pasos que se muestran para retirar el lateral y la parte superior de la cubierta decorativa y pulse el botón de encendido/apagado.

{% include "../.gitbook/includes/tips.md" %}

<mark style="color:blue;">Mantenga pulsado durante más de tres segundos para encender o apagar la energía. Entre en encendido y el apagado deben pasar más de diez segundos.</mark>

<figure><img src="../.gitbook/assets/app-setting2.png" alt=""><figcaption></figcaption></figure>

{% include "../.gitbook/includes/tips.md" %}

<mark style="color:blue;">Las actualizaciones de firmware importantes pueden fallar si el equipo no está conectado a internet durante un período prolongado. Si su equipo no está conectado a internet el sistema le enviará repetidamente un recordatorio. Si el sistema no recibe respuesta de usted durante un período prolongado, el sistema funcionará en condiciones limitadas por razones de seguridad. Si desea que el equipo sea plenamente funcional, conecte el equipo a internet. El sistema restaurará automáticamente su funcionalidad. Si tiene alguna otra pregunta, contáctenos y le ayudaremos.</mark>
