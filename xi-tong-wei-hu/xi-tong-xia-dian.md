# 系统下电/上电

{% include "../.gitbook/includes/danger.md" %}

<mark style="color:red;">高电压、危险： 操作设备时，请穿戴绝缘手套、绝缘鞋、安全帽等防护用具。禁止佩戴金属手镯、戒指、项链等导电饰品。</mark>

### **系统下电**

1. 通过App或者手动操作，关闭设备。

### **App操作：**

在mySigen App中点击“Setting”，可进行开关机操作。

![](<../.gitbook/assets/1 (1).jpeg>)

### **手动操作：**

按照图示步骤将侧边和顶部装饰盖取下，并按下ON/OFF开关按钮即可。

{% include "../.gitbook/includes/tips.md" %}

<mark style="color:blue;">长按＞3s，可实现开机或关机；开机与关机之间需间隔＞10s。</mark>

![](<../.gitbook/assets/3 (1).jpeg>)

{% include "../.gitbook/includes/tips.md" %}

<mark style="color:blue;">如果设备长时间未使用（如设备连续多天处于离线状态或设备运行时间过少），系统将发送提醒。若未收到您的反馈，出于安全考虑，设备将自动关机。若您需要继续使用设备，请联系本公司进行处理。</mark>

2. 断开备电配电单元内与设备连接的开关。
3. 将设备上的“DC SWITCH”旋转至“OFF”状态。
4. 设备LED指示灯均熄灭后，请参考设备上延时标签，等待对应的时间后，再进行操作。

{% include "../.gitbook/includes/waring.md" %}

<mark style="color:orange;">电流与余热。下电后立马操作，可能会造成触电与灼伤。</mark>

### **系统上电**

1. 将设备上的“DC SWITCH”旋转至“ON”状态。
2. 闭合备电配电单元内与设备连接的开关。
3. 通过App或者手动操作，设备开机（操作步骤参见“系统下电”的步骤1描述）。
