# Grid-side Sensor

{% include "https://app.gitbook.com/s/OGIICehJiMvqdVX7wksn/~/reusable/p4FUqXvLmYuzqficHZJF/" %}

* Only power stations with Sigen Hybrid (2.0-6.0) SP2 and Sigen Hybrid (3.0-12.0) TP2 series products can add grid-connection point electricity meters.
* In anti-backflow scenarios, power stations require the installation of a grid-connection point electricity meter.
* The WLAN connected to the electricity meter must be consistent with the WLAN connected to the power station.
