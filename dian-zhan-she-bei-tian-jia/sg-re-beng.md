## Control Mode

On the device interface, click the SG heat pump to set the SG Ready Heat Pump control mode.

<table><thead><tr><th width="49.54547119140625" align="center">No.</th><th width="130.1817626953125">Parameter name</th><th>Description</th></tr></thead><tbody><tr><td align="center">1</td><td>Manual Control</td><td><ul><li>When it is displayed as In Use, you can turn on and off the SG Ready Heat Pump through " <img src="../.gitbook/assets/image (5).png" alt="" data-size="line">" on the App.</li><li>When displayed as Disable, You can click "Enable Manual" to switch to manual mode.</li></ul></td></tr><tr><td align="center">2</td><td>Auto (Time-based)</td><td><ul><li>When displayed as In Use, it indicates automatic control mode. You can modify or create a schedule.</li><li>When displayed as Disable, you can click "Set a Schedule" → "Yes, save and use" to switch to automatic mode.</li></ul></td></tr><tr><td align="center">3</td><td>Schedule</td><td><p>Energy Source Control: Set the Energy Source Type. The following three modes can be set:</p><p><strong>Depends on System</strong></p><ul><li>Battery Boost: When set to <img src="../.gitbook/assets/4 (1).png" alt="" data-size="line">, it can charge using the home battery.</li></ul><p><strong>Surplus PV Only</strong></p><ul><li>Starting Power: Set the starting power of the SG Ready Heat Pump.</li><li>Rated Power: Set the rated power of the connected device, which can be checked on the SG Ready Heat Pump's label.</li><li>Battery Boost: When set to <img src="../.gitbook/assets/4 (1).png" alt="" data-size="line">, the home battery charges the SG Ready Heat Pump.</li></ul><p><strong>Battery Level Control</strong></p><ul><li>Device Activation Threshold: The SG Ready Heat Pump will activate when the actual SOC is greater than the set parameter.</li><li>Device Deactivation Threshold: The SG Ready Heat Pump will deactivate when the actual SOC is less than the set parameter.</li></ul></td></tr><tr><td align="center">4</td><td>Ready by</td><td><ul><li>Activation For: Total running time. Before the time set in Be Ready By, if the running time on that day is less than the set value, the SG heat pump will be turned on.</li><li>Be Ready By: Set the running time. It is used in conjunction with the total running time.</li></ul></td></tr><tr><td align="center">6</td><td>Resume Schedule</td><td>If a schedule has been added, you can click to delete the schedule parameters.</td></tr></tbody></table>

## SG Ready Heat Pump Settings

On the device interface, click SG Ready Heat Pump → Click "<img src="../.gitbook/assets/image (6).png" alt="" data-size="line"> " in the upper right corner to set the SG heat pump parameters.

<table><thead><tr><th width="59.88885498046875" align="center">No.</th><th width="135">Parameter name</th><th>Description</th></tr></thead><tbody><tr><td align="center">1</td><td>General Settings</td><td>Set the SG Ready Heat Pump type, name, and assigned room.</td></tr><tr><td align="center">2</td><td>Operation Settings</td><td><p><strong>PV Excess Setting</strong></p><ul><li>Starting Power: Set the starting power of the SG heat pump.</li></ul><ul><li>Rated Power: Set the rated power of the connected device, which can be checked on the SG heat pump's label.</li></ul><p><strong>Minimum Running Time: Set the minimum running time for the device.</strong><br><strong>Backup Management (When configuring the Gateway in the network setup, this parameter is displayed.)</strong></p><ul><li>When Essential Load is set to<img src="../.gitbook/assets/4 (1).png" alt="" data-size="line"> , the SOC for SG heat pump startup and shutdown can be configured.</li></ul><ul><li>Cut-in: The SG heat pump will activate when the actual SOC is greater than the set parameter.</li><li>Cut-off: The SG heat pump will deactivate when the actual SOC is less than the set parameter.</li></ul></td></tr><tr><td align="center">3</td><td>Remove SG Ready Heat Pump</td><td>Click to remove the SG Ready Heat Pump.</td></tr></tbody></table>
