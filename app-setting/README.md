# Setting\&Tools

## Viewing and upgradingApp version

{% include "../.gitbook/includes/tips.md" %}

<mark style="color:blue;">To gain the best compatibility and performance, you are advised to upgrade the mySigen App regularly.</mark>

* Tap "Settings" → "About" to view the App software version.
* Tap "Settings" → "About" → "Version Update" to upgrade the App software version.
