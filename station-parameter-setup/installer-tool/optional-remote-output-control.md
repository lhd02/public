# (Optional)Remote Output Control

{% include "https://app.gitbook.com/s/OGIICehJiMvqdVX7wksn/~/reusable/p4FUqXvLmYuzqficHZJF/" %}

* <mark style="color:blue;">This function is available only in Japan.</mark>
* <mark style="color:blue;">The inverter remotely connects to the power company's server to obtain dispatch information. Based on the correspondence between time and output value in the dispatch information, it controls the "Maximum Active Power" output of the inverter.</mark>
