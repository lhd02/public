# （可选）远程出力制御

{% include "../../.gitbook/includes/tips.md" %}

* <mark style="color:$danger;">仅日本区域有此功能。</mark>
* <mark style="color:$danger;">逆变器远程连接电力公司服务器获取调度信息，根据调度信息中的时间和出力值的对应关系，控制逆变器的“最大有功功率”输出。</mark>
