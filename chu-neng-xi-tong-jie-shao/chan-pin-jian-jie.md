## Controlador de baterías (SigenStor BC)

Proporciona distribución de la energía, transmisión de comunicaciones y control entre los inversores Sigen Hybrid de las series SP2/ST2 y los paquetes de baterías SigenStor BAT.

| Modelo          | Denominación                             |
| --------------- | ---------------------------------------- |
| SigenStor BC    | Sigen Battery Controller                 |
| SigenStor BC AU | Controlador Sigen Battery para Australia |

## Paquete de baterías (SigenStor BAT)

Puede almacenar energía eléctrica. Admite la utilización simultánea de dos modelos de paquete de baterías.

| Modelo             | Denominación            |
| ------------------ | ----------------------- |
| SigenStor BAT 5.0  | Sigen Battery 5 kWh     |
| SigenStor BAT 6.0  | Sigen Battery de 6 kWh  |
| SigenStor BAT 8.0  | Sigen Battery 8 kWh     |
| SigenStor BAT 10.0 | Sigen Battery de 10 kWh |

## Sensor de energía

Equipado con recogida de datos del punto de conexión a la red para conseguir la funcionalidad de conexión a la red de energía cero.

| Modelo                                          | Denominación                                             |
| ----------------------------------------------- | -------------------------------------------------------- |
| Sigen Sensor SP-DH (SDM230 Modbus)              | Sigen Power Sensor DH monofásico                         |
| Sigen Sensor SP-CT120-DH (SDM120CT 40 mA)       | Sigen Power Sensor con CT externo monofásico DH de 120 A |
| Sigen Sensor TP-DH（SDM630MODBUS V2）             | Sigen Power Sensor DH trifásico                          |
| Sigen Sensor TP-CT120-DH(SDM630MCT 40 mA/120 A) | Sigen Power Sensor con CT externo trifásico DH de 120 A  |
| Sigen Sensor TP-CT300-DH（SDM630MCT 40 mA/300 A） | Sigen Power Sensor con CT externo trifásico DH de 300 A  |
| Sigen Sensor TP-CT600-DH（SDM630MCT V2/600 A）    | Sigen Power Sensor con CT externo trifásico DH de 600 A  |

## Módulo de comunicación (CommMod)

Si se utiliza con nuestros inversores, la comunicación entre inversores y sistemas de gestión debe realizarse mediante 4G.

| Modelo        | Denominación               |
| ------------- | -------------------------- |
| Sigen CommMod | Sigen Communication Module |
