# Omvormer

* De SigenStor EC omvormer kan gebruikt worden in PV-opslagscenario's en moet gebruikt worden in combinatie met PV-modules en SigenStor BAT.
* De Sigen Hybrid Inverter kan alleen gebruikt worden in PV-scenario's in combinatie met PV-modules. Het kan ook worden gekocht en geactiveerd met een speciale licentie om naast PV-modules en SigenStor BAT te werken in een PV-opslagsysteem.
