# Falownik

* Falownik SigenStor EC może być używany do magazynowania energii fotowoltaicznej, wymagane użytkowanie wraz z modułami fotowoltaicznymi oraz akumulatorem SigenStor BAT.
* Sigen Hybrid Inverter może być wykorzystywany samodzielnie w instalacjach PV w połączeniu z modułami PV. Można go również zakupić i aktywować z konkretną licencją do pracy z modułami PV oraz akumulatorem SigenStor BAT w instalacji magazynującej energię PV.
