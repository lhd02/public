# Inverter

* SigenStor EC inverter can be used in PV storage scenarios and needs to be used in conjunction with PV modules and SigenStor BAT.
* SigenStor AC inverter can be used in pure storage applications and needs to be used in conjunction with SigenStor BAT.
* Sigen Hybrid inverter can be used alone in PV scenarios in conjunction with PV modules. It can also be purchased and activated with a designated license to work alongside PV modules and SigenStor BAT in a PV storage system.
