# Inversor

* SigenStor EC puede usarse en escenarios de almacenamiento fotovoltaico y debe utilizarse junto con módulos FV y SigenStor BAT.
* El Sigen Hybrid Inverter puede usarse él solo en escenarios fotovoltaicos junto con módulos fotovoltaicos. También puede adquirirse y activarse con una licencia designada para trabajar junto a módulos fotovoltaicos y SigenStor BAT en un sistema de almacenamiento fotovoltaico.
