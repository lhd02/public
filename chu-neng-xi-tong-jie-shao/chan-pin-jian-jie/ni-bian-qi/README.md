# Inverter

* L'inverter SigenStor EC può essere utilizzato per l'accumulo fotovoltaico e deve essere usato insieme ai moduli fotovoltaici e a SigenStor BAT.
* L'Sigen Hybrid inverter può essere utilizzato in scenari fotovoltaici insieme ai moduli fotovoltaici. Può anche essere acquistato e attivato con una licenza designata per essere utilizzato insieme ai moduli fotovoltaici e a SigenStor BAT in un sistema di accumulo fotovoltaico.
