# Onduleur

* L'onduleur SigenStor EC est adapté aux scénarios de stockage photovoltaïque et doit être utilisé conjointement avec des modules photovoltaïques et le système SigenStor BAT.
* Sigen Hybrid Inverter peut être utilisé seul dans les scénarios de système photovoltaïque en association avec des modules photovoltaïques. Il peut également être acheté et activé avec une licence spécifique lui permettant de fonctionner avec les modules photovoltaïques et le système SigenStor BAT dans un système de stockage photovoltaïque.
