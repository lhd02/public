# Invertteri

* SigenStor EC -invertteriä voidaan käyttää aurinkosähkön varastoinnissa ja sitä täytyy käyttää yhdessä aurinkopaneelien ja SigenStor BAT -akkuyksiköiden kanssa.
* Sigen Hybrid -invertteriä voidaan käyttää yksinään aurinkosähkökäytössä yhdessä aurinkopaneelien kanssa. Sen voi myös ostaa ja aktivoida erityisellä lisenssillä, jolloin se toimii yhdessä aurinkopaneelien ja SigenStor BAT -akkuyksiöiden kanssa aurinkosähkön varastointijärjestelmässä.
