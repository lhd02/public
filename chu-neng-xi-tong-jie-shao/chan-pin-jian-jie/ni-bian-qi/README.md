# Inverter

* SigenStor EC-inverteren kan bruges i PV-lagringsscenarier og skal bruges sammen med PV-moduler og SigenStor BAT.
* Sigen Hybrid-inverter kan bruges alene i PV-scenarier sammen med PV-moduler. Det kan også købes og aktiveres med en særlig licens til brug sammen med PV-moduler og SigenStor BAT i et PV-lagringssystem.
