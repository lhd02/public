# Växelriktare

* SigenStor EC-växelriktare kan användas i scenarion där solel ska lagras och måste användas tillsammans med solcellsmoduler och SigenStor BAT.
* Sigen Hybrid Inverter kan användas fristående i scenarion med solceller tillsammans med solcellsmoduler. Den kan även inhandlas och aktiveras med en speciell licens för att fungera med solcellsmoduler och SigenStor BAT i ett system för lagring av solel.
