# Capteur CT

Équipé d'un système de collecte de données sur les points de connexion au réseau afin d'obtenir une connexion au réseau électrique sans consommation d'énergie. Ce produit n'est utilisé que dans les onduleurs de systèmes à phase divisée.

| Nom du produit | Modèle | Nom         |
| -------------- | ------ | ----------- |
| Capteur CT     | CT-EC  | External CT |
