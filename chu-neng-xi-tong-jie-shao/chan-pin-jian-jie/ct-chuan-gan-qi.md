# CT-sensor

Utrustad med datainsamling vid anslutningspunkten till elnätet för att möjliggöra funktionen för anslutning till elnätet utan kraftleverans. Denna produkt används endast i växelriktare för enfassystem med hjälpfas.

| Produktnamn | Modell | Namn        |
| ----------- | ------ | ----------- |
| CT-sensor   | CT-EC  | External CT |
