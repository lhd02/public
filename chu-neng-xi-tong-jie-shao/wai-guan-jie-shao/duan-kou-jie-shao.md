# 端口介绍

### **SigenStor EC左视图**

![](../../.gitbook/assets/0.jpeg)

| 序号 | 名称        | 丝印                   |
| -- | --------- | -------------------- |
| 1  | 直流开关      | DC SWITCH            |
| 2  | 装饰盖灯带接口   | LED                  |
| 3  | 天线接口      | ANT                  |
| 4  | 网线接口      | RJ45 1/ RJ45 2       |
| 5  | 交流输出接口    | AC                   |
| 6  | 接地螺钉      | -                    |
| 7  | RS485通信接口 | COM                  |
| 8  | CommMod接口 | 4G                   |
| 9  | 直流输入接口    | PV1+/PV2+/ PV1-/PV2- |
| 10 | 开关按钮      | ON/OFF               |
