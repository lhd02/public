# Configuring parameters on the "App Setting" screen

Click "Setting" → "App Setting" to go to the settings screen.

Dark Mode

Specifies the display style.

Language

Specifies the display language.

Temperature Unit

* Sets the unit of temperature.
* The unit of temperature commonly used in the local area is set by default. You can change this setting when needed.

Notification

Sets the App push notification permission.

This permission is set while the App is installed. You can make settings when needed.

Lab

Sets the access permission of Sigen AI.

You can ask Sigen AI about the product knowledge when the parameter is set to ![](<../.gitbook/assets/0 (6).png>).

Diagnostic tool

If an exception occurs when you use the App, you can use this tool to generate operation logs and report to our customer support for analysis and solutions.
