# 设置&工具

## App软件版本查看与升级

{% include "../.gitbook/includes/tips.md" %}

<mark style="color:blue;">为获得最佳的兼容性与性能，mySigen App建议定期进行升级。</mark>

* 点击“Setting”→“About”可查看App软件版本。
* 点击“Setting”→“About”→“Version Update”可升级App软件版本。
