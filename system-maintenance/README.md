# Systemwartung

{% include "../.gitbook/includes/danger.md" %}

* <mark style="color:red;">Führen Sie keine Betriebsvorgänge am eingeschalteten Gerät aus. Vergewissern Sie sich vor der Inbetriebnahme, dass alle Stromversorger zu den Geräten getrennt wurden, einschließlich, aber nicht beschränkt auf die Netzseite, die Wechselrichter und die Generator-Netzschalter.</mark>
* <mark style="color:red;">Entfernen Sie die Innenplatte nicht. Um die Innenplatte zu entfernen, wenden Sie sich an Ihren Installateur oder Vertriebsmitarbeiter.</mark>
