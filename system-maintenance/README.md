* <mark style="color:red;">Non eseguire alcun intervento sul dispositivo mentre è acceso. Prima di eseguire qualsiasi intervento, assicurarsi che tutte le alimentazioni del dispositivo siano state scollegate, compresi gli interruttori di alimentazione del lato rete, dell'inverter e del generatore.</mark>
* <mark style="color:red;">Non rimuovere il pannello interno. Per rimuovere il pannello interno, contattare l'installatore o il rappresentante commerciale per ricevere assistenza.</mark>
