# Entretien du système

{% include "../.gitbook/includes/danger.md" %}

* <mark style="color:red;">N'effectuez pas d'opérations sur l'équipement lorsqu'il est sous tension. Avant toute opération, assurez-vous que toutes les sources d'alimentation de l'équipement ont été déconnectées, y compris, mais sans s'y limiter, les interrupteurs d'alimentation du côté du réseau, de l'onduleur et du générateur.</mark>
* <mark style="color:red;">Ne retirez pas le panneau intérieur. Pour retirer le panneau intérieur, contactez votre installateur ou votre représentant commercial pour obtenir de l'aide.</mark>
