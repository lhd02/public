# 非常時の処置

### **火災による非常事態**

{% include "../../.gitbook/includes/danger.md" %}

* <mark style="color:red;">機器をシャットダウンするか、安全が確保される場合にはメイン電源スイッチの接続を解除してください。</mark>
* <mark style="color:red;">高温によりバッテリーパックが歪んだり損傷したりして電解液漏れや有毒ガスが発生するおそれがあります。バッテリーパックに近寄らず、また保護用具を着用してください。</mark>
* <mark style="color:red;">火災が小さなものである場合、二酸化炭素系やABC粉末系の消火器を使って火災を消火してください。</mark>
* <mark style="color:red;">火が燃え広がっている場合、建物や機器エリアから速やかに退去して消防署に連絡してください。炎上中の建物への再度の入室は禁止します。</mark>
* <mark style="color:red;">消火活動中には高圧部に触れたり接触したりしないようにしてください。感電する危険があります。</mark>
* <mark style="color:red;">消火を終えた後の機器を使用してはなりません。最寄りの設置業者に連絡してください。</mark>

### **洪水による非常事態**

{% include "../../.gitbook/includes/danger.md" %}

* <mark style="color:red;">機器をシャットダウンするか、安全が確保される場合にはメイン電源スイッチの接続を解除してください。</mark>
* <mark style="color:red;">バッテリーパックが冠水した場合、感電防止のため触らないようにしてください。</mark>
* <mark style="color:red;">洪水が引いた後で機器を使用してはなりません。最寄りの設置業者に連絡してください。</mark>

### **バッテリーパックの故障による非常事態**

{% include "../../.gitbook/includes/danger.md" %}

* <mark style="color:red;">バッテリーパックから異臭がしたり、電解液漏れや過熱していた場合、触れたりせずに直ちに専門の担当者に連絡してください。専門の担当者は身を守るためゴーグル、ゴム手袋、ガスマスクや防護服などの保護用具を着用する必要があります。</mark>
* <mark style="color:red;">電解液は腐食性で接触すると肌の炎症や化学熱傷の原因となる可能性があります。電解液に誤って接触してしまった場合、直ちに以下の措置を講じてください：</mark>
* <mark style="color:red;">吸引した場合: 汚染された領域から退去し、新鮮な空気で通気し、直ちに医師の診察を受けてください。</mark>
* <mark style="color:red;">眼に入った場合: 少なくとも15分間ほど大量の水で眼を洗い流してください。眼をこすったりしないでください。直ちに医師の診察を受けてください。</mark>
* <mark style="color:red;">皮膚に付着した場合: 接触部位を大量の石鹸水で洗い、直ちに医師の診察を受けてください。</mark>
* <mark style="color:red;">摂取した場合: 無理に吐かせ、直ちに医師の診察を受けてください。</mark>
* <mark style="color:red;">異常のあるバッテリーパックの使用を継続せず、最寄りの設置業者に連絡してください。</mark>

### **バッテリーパックの落下や衝撃による非常事態**

* 顕著な異臭、煙や火が出た場合、直ちに機器から離れ、専門の担当者に連絡してください。
* 落としたり、何かに衝突したバッテリーパックを使用しないでください。最寄りの設置業者に連絡してください。
