# Wyłączanie zasilania

{% include "../../.gitbook/includes/warning.md" %}

* <mark style="color:orange;">Gdy sprzęt jest uszkodzony, natychmiast odłączyć wszystkie wyłączniki automatyczne urządzenia, sprawdzić i usunąć usterkę przed ponownym włączeniem.</mark>
* <mark style="color:orange;">Nie używać wyłączników automatycznych, które nie są podłączone do danego urządzenia, gdy urządzenie jest wyłączone. Pozostawić wyłączniki automatyczne w stanie rozłączonym.</mark>
