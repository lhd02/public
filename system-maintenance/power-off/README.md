# Mise hors tension

{% include "../../.gitbook/includes/warning.md" %}

* <mark style="color:orange;">Si l'équipement est défectueux, coupez immédiatement tous les disjoncteurs de l'équipement, puis vérifiez et éliminez la panne avant de remettre l'équipement en marche.</mark>
* <mark style="color:orange;">N'actionnez pas les disjoncteurs qui ne sont pas connectés à l'équipement correspondant lorsque l'équipement est hors tension. Gardez ces disjoncteurs coupés.</mark>
