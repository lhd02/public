# Generalidades

### **Introducción**

Este documento presenta básicamente los inversores Sigen Hybrid (2.0-6.0) de la serie SP2, Sigen Hybrid (3.0-12.0) de la serie TP2 y el sistema de almacenamiento de energía SigenStor y abarca la presentación del producto, el cableado del sistema y el funcionamiento y mantenimiento del sistema.

### **Audiencia**

Este documento es adecuado para usuarios del producto y profesionales.
